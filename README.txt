DRAYKO UNIVERSAL v2 — UI + controles de teste

INSTALAÇÃO NO ROBLOX STUDIO
1. Abra o seu próprio jogo no Roblox Studio.
2. Em Explorer, vá para StarterPlayer > StarterPlayerScripts.
3. Crie um LocalScript chamado DraykoUniversal.
4. Copie todo o conteúdo de main.lua para esse LocalScript.
5. Clique em Play para testar.
